# Существо, которое учится убивать в Minecraft

Обучение с подкреплением в Minecraft **без MineRL и без Malmo**. Своя лаборатория:
глаза, руки, консоль и арена написаны с нуля на голом Windows API и сокетах.

Из внешнего только сам Minecraft и PyTorch. Ни одной заброшенной библиотеки-посредника.

## Результат

| | старая лаборатория (MineRL) | своя лаборатория |
|---|---|---|
| убийств | **0** за 176 494 шага | **125** за 21 087 шагов |
| доля побед | — | 97% (последние 20 боёв — 95%) |
| шагов на бой | — | 76 против 204 в начале |
| урон за бой | — | 19.9 из 20 возможных |

Мозг при этом **тот же самый** — те же глаза, тот же накопленный опыт. Разница только
в лаборатории.

## Почему ушли от MineRL

Три беды, которые внутри той сборки было не починить:

* **касса за урон врала.** Считала урон по расчёту клиента и занижала его
  неравномерно: 28% настоящего урона при заряженном ударе, 51% при долбёжке.
  То есть за сильный удар платили относительно меньше — существо честно училось
  худшему способу.
* **зомби горел и поджигал существо.** Мир рождается днём и лишь потом переходит
  в ночь; за эти секунды солнце подпаливало моба, а горящий моб поджигает цель.
  В логах шло `1.0 damage from onFire` — боль, которой существо не могло избежать.
* **голод молча отнимал лечение.** Сытость падала до единицы, а восстановление
  здоровья в Minecraft работает только при сытости 18 и выше. Отход «подлечиться»
  не работал вовсе, и понять это изнутри было невозможно.

Плюс сама сборка заброшена: мёртвые артефакты при установке, java-заглушки, которые
приходилось вырезать патчем, и зависания сборки Gradle.

## Как устроено

```
mc-lab/
├── telo/          ТЕЛО существа — чем видит, чем действует
│   ├── glaza.py     снимок окна игры → кадр 64×64 (ctypes, BitBlt)
│   ├── ruki.py      клавиши по скан-кодам и мышь приращениями (SendInput)
│   ├── konsol.py    свой протокол RCON на голых сокетах
│   ├── arena.py     загон командами, сброс боя, точные счётчики игры
│   └── mir.py       среда обучения: чувства, 15 действий, награда
│
├── zapis.py       РАБОЧИЙ ЦИКЛ — запись показа человека
├── uchit.py         разминка подражанием + наращивание головы мозга
├── obuchenie.py     обучение с наградой
│
├── proby/         ПРОВЕРКИ — каждая отвечает на один вопрос фактами
│   ├── proba_tela.py      доходят ли глаза и руки до живой игры
│   ├── proba_myshi.py     каким способом поворачивается обзор
│   ├── proba_povorota.py  сколько градусов даёт какой сдвиг мыши
│   └── proba_mira.py      работает ли круг «увидел — сделал — получил»
│
├── zapusk/        ПУСКОВЫЕ — по ним щёлкают
├── models/        мозги (в историю не попадают: 4.5 МБ каждые 2000 шагов)
├── pokaz/         записи твоей игры (в историю ПОПАДАЮТ: их не восстановить)
├── logs/          графики обучения
└── server/        сервер Minecraft (файл Mojang, перевыкладывать нельзя)
```

Правда о бое всегда берётся **у сервера**, а не из наших расчётов: координаты,
углы обзора, нанесённый урон, убийства. Поэтому проверкам нечем соврать.

Награда берётся из **собственных счётчиков Minecraft** — `damage_dealt` в десятых
долях здоровья и `killed:zombie`. Не из посредника, который может врать.

## Что нужно

* Minecraft 1.16.5 (обычный клиент) и официальный `server.jar` в `server/`
* Java 8, Python с torch, stable-baselines3, numpy, opencv
* Windows: лаборатория опирается на системный ввод и захват экрана

Сервер поднимается `server.bat`, клиент подключается на `127.0.0.1`.
Окно игры должно быть впереди — существо видит экран.

## Порядок работы

Всё пусковое лежит в `zapusk/`, щёлкать по нему:

```
zapusk\server.bat      поднять сервер, потом зайти клиентом на 127.0.0.1
zapusk\zapis.bat       записать показ (играешь сам, обычной мышью)
zapusk\obuchenie.bat   обучение с наградой
```

Разминка подражанием — `python uchit.py` из корня (Minecraft для неё не нужен).

Проверки, если что-то ведёт себя странно:

```
zapusk\proba.bat        глаза и руки на живой игре
zapusk\mysh.bat         каким способом поворачивается обзор
zapusk\povorot.bat      сколько градусов даёт сдвиг мыши
zapusk\proba-mira.bat   круг «увидел — сделал — получил»
```

`Escape` ставит обучение на паузу: зомби застывают, мышь освобождается.
`Ctrl+C` в консоли — закончить, мозг сохранится.

## Уроки, добытые дорого

* награду брать только из счётчиков самой игры, а не у посредника;
* загону нужна крыша, иначе солнце жжёт зомби, а тот поджигает существо;
* новые действия дописывать **только в конец** и наращивать голову мозга,
  перенося прежние слои — иначе весь накопленный опыт обесценивается;
* усложнять противника, а не человека: здоровье человека нормируется на 40,
  и его снижение сломало бы разметку показа;
* показ обязан содержать **работающий** способ. Прибавка скорости зомби делала
  отступление бессмысленным — существо скопировало бы проигрышную повадку;
* цену боли поднимать можно только когда награда уже достижима. Иначе вырастает
  трус: в старой лаборатории убийство было недостижимо, и существо выучило убегать.

## Дальше

Лестница сложности (зомби с мечом → трое), затем память — несколько кадров или
рекуррентность, чтобы существо видело **движение**, а не одну застывшую картинку.
Без памяти предсказать уклон живого игрока невозможно в принципе.
